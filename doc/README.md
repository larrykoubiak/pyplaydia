# Research notes

The [F2 control investigation](f2/README.md) records current observations and
open hypotheses about scene flags, still screens, and interactive playback.

## Historical research

These files preserve material used during the original reverse-engineering
work. They are not needed to run the extractor or decoder.

| File | Historical use |
|---|---|
| [headers.xlsx](headers.xlsx) | Frame-header analysis. |
| [footers.xlsx](footers.xlsx) | Frame-footer analysis. |
| [JPEG_Ref_Tables.xlsm](JPEG_Ref_Tables.xlsm) | JPEG reference tables used during early investigations. |
| [JPH06178281A.pdf](JPH06178281A.pdf) | Patent consulted while investigating the codec. |

Labels and interpretations in these research files may reflect superseded
hypotheses. The JPEG tables and patent are historical references, not a
specification of the implemented codec.

See the [project README](../README.md) for the current codec model and usage,
and [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) for credits. Earlier
notes and session handoffs remain in Git history.
